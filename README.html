BRIVW

The BRIVW R package implements the bivariate rerandomized inverse variance weighted estimator for Mendelian randomization with winner's curse and sample structure. It also provides the BMEI test to assess departures from the balanced pleiotropy and InSIDE conditions.

Installation

Install or update BRIVW from GitHub:

# Run once if remotes is not installed:
# install.packages("remotes")
remotes::install_github("XinLiu-stats/BRIVW", force = TRUE, upgrade = "never")

Input data

The brivw() function requires four vectors of GWAS summary statistics:

  • gamma_hat: estimated SNP-exposure associations;
  • gamma_se: LDSC-calibrated standard errors for gamma_hat;
  • Gamma_hat: estimated SNP-outcome associations;
  • Gamma_se: LDSC-calibrated standard errors for Gamma_hat.

The input SNPs must already have undergone allele harmonization, randomized IV selection, and LD pruning. Supply the same eta and lambda values used for IV selection, without rounding the threshold.

If se_exposure and se_outcome are the original GWAS standard errors, calibrate them using the LDSC intercepts before calling brivw():

gamma_se <- sqrt(c1) * se_exposure
Gamma_se <- sqrt(c2) * se_outcome
rho <- c12 / sqrt(c1 * c2)

Here, c1 and c2 are the exposure and outcome single-trait LDSC intercepts, and c12 is the cross-trait LDSC intercept. Do not apply this calibration again if the supplied standard errors have already been calibrated. In the absence of sample structure, use c1 = c2 = 1 and c12 = 0, so the original standard errors are retained and rho = 0.

BMEI allele coding

BMEI uses exposure-increasing allele coding (all-positive coding). For SNPs with negative input gamma_hat, the function reverses both gamma_hat and Gamma_hat before Rao-Blackwellization. This recoding is handled automatically and leaves the BRIVW estimate unchanged for the same selected SNPs.

The output bmei_p_value is the two-sided BMEI P-value from the standard normal distribution. In version 0.2.0, this replaces the combined BMEI-C P-value; the function arguments and output column names are unchanged.

Example: BMI and systolic blood pressure

The package includes an analysis-ready BMI-SBP dataset. Its standard errors are already LDSC-calibrated. The corresponding LDSC intercept matrix is provided as BMI_UKB_SBP_C.

library(BRIVW)

data("BMI_UKB_SBP", package = "BRIVW")
data("BMI_UKB_SBP_C", package = "BRIVW")

# The example standard errors are already LDSC-calibrated.
# Use the exact two-sided IV-selection threshold.
lambda <- qnorm(5e-5 / 2, lower.tail = FALSE)
rho <- BMI_UKB_SBP_C[1, 2] /
  sqrt(BMI_UKB_SBP_C[1, 1] * BMI_UKB_SBP_C[2, 2])

fit <- brivw(
  gamma_hat = BMI_UKB_SBP$gamma_hat,
  gamma_se = BMI_UKB_SBP$gamma_se,
  Gamma_hat = BMI_UKB_SBP$Gamma_hat,
  Gamma_se = BMI_UKB_SBP$Gamma_se,
  rho = rho,
  eta = 0.5,
  lambda = lambda,
  sig.level = 0.95
)

fit

The output includes the causal-effect estimate (estimate), its standard error (std_error), confidence limits (ci_lower and ci_upper), causal-effect P-value (p_value), number of SNPs (n_snp), and BMEI P-value (bmei_p_value). A nonsignificant BMEI result does not establish that all pleiotropy assumptions hold.

To run this example directly from the local package source, open the package project in RStudio and run:

source("examples/BMI_SBP.R")
